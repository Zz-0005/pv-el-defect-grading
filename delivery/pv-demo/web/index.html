光伏电池片 EL 图像缺陷分级

用 YOLOv8 分类头把一片电池片的电致发光图像判成三档—— 合格 / 待复核 / 判废，并给出处置动作与缺陷热力图。 数据是 ELPV 公开的 2624 张真实产线 EL 图像，全部指标可在本机一条命令复现。

一概览

先说结论：这套系统解决的不是"有没有缺陷"（那是二分类，一句话就完了），而是"有多严重、该判废还是返修"——因为产线上的处置动作完全取决于档位。

这套系统现在能做什么、不能做什么：
能：把一片电池片按严重度分成三档，给出处置建议，并指出模型关注的位置。
不能：直接用于产线判废。分级档位来自数据集标注，不是 IEC 判废标准；判废漏判率 34.9% 也还不能接受。它的价值是证明方法可行、指标可复现、边界清楚。

三数据来源（真实产线 EL 图像）

ELPV Dataset（Buerhop-Lutz 等，EU PVSEC 2018）：2624 张 300×300 8 位灰度电致发光图像，来自 44 块真实光伏组件，每张带人工标注的缺陷概率与晶型（单晶 1074 / 多晶 1550）。

为什么选它

  • 是真实产线图像，不是渲染合成；
  • 缺陷概率只有 4 个离散取值（0.0 / 1/3 / 2/3 / 1.0），所以"分级"是数据集本身的标注粒度，不是我为凑任务切的；
  • 体量小（93 MB），全部可在本机复现。

必须说明的两点

  • 分级档位来自数据集标注，不是行业判废标准（IEC 61215 更细）；
  • 没有缺陷类型标注（隐裂/断栅/黑斑），只有整体严重度。

四模型与类别映射

档位含义（数据集标注）处置动作
合格缺陷概率 0.0正常流转
待复核缺陷概率 1/3 ~ 2/3返修 / 降级
判废缺陷概率 1.0判废

模型：YOLOv8s-cls 微调后导出 ONNX（20.3 MB）。输入 1×3×224×224，输出 3 类 softmax 概率（和恒为 1）。

这里有个容易踩的坑：ultralytics 分类头的输出已经是 softmax 概率，再套一次 softmax 会把分布二次压缩。我一开始就踩了，导致热力图解释的概率与推理概率最大偏差 0.52，等于解释的不是模型的结论。

五系统架构：基线在哪儿，我改了什么

被问"你这就是调了个 YOLO 吗"，答案在这一节。调 YOLO 是最后一步，前面三件事才是这个项目的主体：

① 切分

2624 张图来自 44 块组件，相邻电池片成像几乎一致。按图片随机切分，孪生样本会同时进训练和测试，指标虚高。

做法：用 16×16 外观向量 k-means 还原组件分组，按组切分，并做两道泄漏检查。

② 分级粒度

先做四级（良好/轻微/中度/严重），结果中间两档召回都是 0——模型直接放弃这两类。加过采样后有恢复但仍是最弱环节。

做法：合并成三档操作级，把"轻微/中度"并成"待复核"，两者在产线上的动作本就同属返修/降级。

③ 拒识

纯 argmax 会把没把握的样本硬塞进某一档。

做法：固定人工预算，把最没把握的 5% 转人工复核。宏 F1 0.621→0.638，代价降 6%，准确率只掉 0.5 个点。

9.2 拒识预算：把最没把握的 q% 转人工

这一节记录一次失败后再做对的过程。我先按业务代价做无约束优化，算法给出的解是"置信度低于 90% 就判待复核"——代价降 57%，但它把 73% 的合格品都标成了待复核。这不是模型变好，是评价函数允许它作弊（代价表里"多看一眼"只记 1 分，"漏掉判废"记 20 分）。

所以把约束加回去：人工复核有预算上限，只转最没把握的 q%。

看完这些错例要承认一件事：模型学到的不完全是"缺陷的局部形态"，很大程度上是整片电池的明暗。所以同色浅缺陷、油膜覆盖、跨视野裂纹这三类它必然弱。这不是调参能解决的，需要更好的成像或检测式模型。

十一从「分级」到「处置动作」

分级如果落不到动作上，就只是给数据集编了个号。三档对应的动作是：

输出产线动作谁执行
合格正常流转，不干预自动
待复核返修 / 降级，或人工看一眼复核岗
判废剔除，登记不良品自动 + 质检

配合拒识策略，系统实际有三条出口：自动放行、自动剔除、推人工。这样它就不是"一个打分器"，而是"一个能决定下一步谁来做的东西"。

十二局限与后续计划

必须承认的五条

  1. 分级档位不是行业判废标准；
  2. 组件分组是近似还原（k-means），不能保证零泄漏；
  3. 没有缺陷类型，只有严重度；
  4. 单晶/多晶混合训练，未分型建模；
  5. 跨组件泛化是真正的瓶颈：训练损失 0.18、验证损失 1.34，模型在记训练组件。

下一步三件事

  1. 找一家组件厂拿真实判废记录，用他们的档位重新标标签；
  2. 补采「待复核」这一类（目前只有 57 张测试样本）；
  3. 把分类模型换成检测/分割式监督，让热力图能给出缺陷轮廓，而不只是注意力。
