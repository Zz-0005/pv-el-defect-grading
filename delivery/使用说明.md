# 光伏电池片 EL 缺陷分级 · 交付包

这个包里是完整的课程设计成果：**离线技术报告、已标注数据、ONNX 权重、
推理与评估脚本、答辩 PPT**。不需要 torch，不需要显卡，双击就能演示。

---

## 一、最快用法

| 方式 | 做什么 |
|---|---|
| 双击 **`启动_报告与演示.pyw`** | 先打开技术报告网页，再启动本地演示服务（浏览器里可以**上传你自己的 EL 图**试一下） |
| 双击 **`只看技术报告.pyw`** | 只打开离线技术报告，不启动任何服务 |
| 双击 **`启动.bat`** | 命令行方式启动演示服务（`.pyw` 不灵时的备用） |
| 直接打开 **`pv-demo\web\index.html`** | 技术报告是纯静态网页，**不联网**也能看 |

> 第一次用请先装依赖（只需 4 个包，约 120 MB）：
> ```
> pip install -r pv-demo\requirements.txt
> ```

### 在网页里看什么

技术报告共 **13 章**，重点四块：

1. **七、分级效果**：7 张精挑演示图，点「原图 / 数据集真值 / 模型预测」切换，
   **← →** 翻页。其中刻意保留了 1 张判错的难例
2. **八、评估指标**：582 张冻结测试集上的准确率、分类别 P/R/F1、混淆矩阵
3. **九、A/B 公平对照**：四组实验、泄漏对照、拒识预算表
4. **十、失败案例**：按业务代价排出的 9 张最危险错例

### 在演示服务里做什么

打开 `127.0.0.1:8000`，把任意一张 EL 图片拖进去，点「开始检测」，
三档判定 + 处置动作 + 三档概率立刻出来，单张约 8 ms。

**现场建议**：先拖一张预热（首张约 60 ms，之后约 8 ms），再正式演示。

- **数据**：ELPV Dataset（Buerhop-Lutz 等，EU PVSEC 2018），CC-BY-NC-SA-4.0

## 五、换一台电脑怎么用

只需要 Python 3.10+ 和四个 pip 包：

```powershell
python -m pip install -r pv-demo\requirements.txt
```

然后把快捷方式重建一下：在本包里**右键 `创建快捷方式.ps1` → 使用 PowerShell 运行**，
它会自动找 `pythonw.exe` 并在桌面建三个快捷方式。

> 因为 `pythonw.exe` 的路径因机器而异，快捷方式才需要重建；
> 报告本身是静态网页，换机器双击 `pv-demo\web\index.html` 也能看。

## 六、常见问题

**双击没反应？** 看本目录下 `启动日志.txt`。多半是 Python 没装或没加进 PATH。

**浏览器没打开？** 手动双击 `pv-demo\web\index.html`，报告是离线文件。

**演示服务报 "No module named onnxruntime"？** 说明依赖没装：
`pip install -r pv-demo\requirements.txt`。

**端口 8000 被占用？** 用 `python tools\serve_onnx.py --port 8010`（在 `pv-demo` 目录下）。

**能训练吗？** 训练不在本包范围内（需要 torch 与 GPU）。
本包提供的是**已训练模型的推理、评估与复现**。

## 七、关于"合格只有 0.8"这件事

演示时评委很可能问：**为什么判废是 1.00，合格只有 0.84~0.87？**

这不是模型不确定，而是两类问题的性质不同：

- **判废有证据**：暗斑、裂纹摆在那里，模型很确定（全测试集置信度中位 1.00）
- **合格没有证据**：一片均匀的电池片，模型只能说"没看到问题"（中位 0.80）

所以演示页不再只显示一个百分比，而是显示**判定依据**：

`
判定依据：合格 0.87，次高 待复核 0.08，差距 0.79
把握 高
`

看的是**差距**（top1 - top2），不是绝对值。差距 < 0.2 时，页面会直接提示
「⚠ 系统把握不足，建议人工复核后再放行」——系统不会在没把握的时候替你放行。

完整台词见 演示脚本.md 第三节。
