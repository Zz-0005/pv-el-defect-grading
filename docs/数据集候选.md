# 公开数据集候选（本机实测版）

> 这份清单不是从网上抄的，是**在你这台机器上实测**过的：
> 哪个能打开、哪个能下、下下来是不是真图像。复测脚本：`scripts/probe_datasets.py`
>
> 实测时间：2026-11-24。网络环境会变，结论过期就重跑一次脚本。

## 一、结论先看

| 结论 | 说明 |
|---|---|
| 本项目已用 | **ELPV**（2624 张 EL，真实组件，有缺陷概率标注） |
| 今天新增可用 | **DM-PV**（2376 对红外+可见光，6 类，YOLO 格式）— 已下 50 对验证 |
| 想要但拿不到 | **PVEL-AD**（36,543 张 EL，12 类带框）— 数据在 Google Drive，本机不可达 |
| 想都别想 | HuggingFace、Kaggle、Roboflow、Papers with Code — 本机全部连不上 |

## 三、真正能下、且是真实图像的数据集

### 1. ELPV（本项目已在用）

- 仓库：`https://github.com/zae-bayern/elpv-dataset`
- 规模：2624 张 300×300 灰度 EL 图像，来自 **44 块真实光伏组件**
- 标注：每张带缺陷概率（0.0 / 1/3 / 2/3 / 1.0）与晶型（单晶/多晶）
- 体积：仓库 zip 约 93 MB，**图像直接在仓库里**
- 许可：CC-BY-NC-SA-4.0（非商业）
- 获取：`python scripts/fetch_data.py`

### 2. DM-PV（今天新验证，可用）

- 仓库：`https://github.com/Lanpangzihzn/DM-PV-dataset`
- 规模：**2376 对**红外 + 可见光图像（各 2376 张），1280×1024 RGB
- 类别 6 个：`Single Hotspot` / `Large-area Hotspot` / `Diode Short Circuit` /
  `Bird Droppings` / `Weed Occlusion` / `Sunlight Reflection`
- 标注：**标准 YOLO 格式**（`class cx cy w h`，已归一化）
- 关键坑：**图像用 Git LFS 存储**，普通 zip 下下来是 131 字节的指针文件，
  而且本机没装 git-lfs。但 LFS 内容可以从 `media.githubusercontent.com` 直接取，
  脚本已经处理了这一点。
- 实测速度：50 对（100 张图 + 43 个标注，61 MB）用时 208 秒，约 0.29 MB/s
- 全量约 3.1 GB，按这个速度需要 **3 小时左右**
- 许可：仓库**没有 LICENSE 文件**。用于答辩演示可以，**不要再分发**，引用原论文
- 获取：`python scripts/fetch_dmpv.py --limit 50 --modality both`

> 注意：DM-PV 是**无人机巡检视角的组件级缺陷**（热斑、鸟粪、遮挡、反光），
> 不是电池片级 EL 隐裂。它不能直接替代 ELPV，但非常适合做**跨场景泛化**实验：
> "同一个模型在电池片级和组件级上的表现差多少，为什么。"

## 四、想要但本机拿不到的

### PVEL-AD（最可惜的一个）

- 规模：**36,543 张**近红外 EL 图像，**12 类缺陷**，**40,358 个标注框**
- 类别：crack（线状/星状）、finger interruption、black core、thick line、scratch、
  fragment、corner、printing_error、horizontal/vertical_dislocation、short_circuit
- 许可：Apache-2.0（代码）
- 仓库：`https://github.com/binyisu/PVEL-AD`（★175）
- **但**：仓库只有 7.8 MB 代码和示意图，**数据在 Google Drive**
  （README 里还要求填 `Industrial_Data_Access_Form.docx` 申请）
- 本机测试：Drive 不可达，仓库页有一次 HEAD 超时

> 如果哪天能拿到，这是**最值得换的数据集**：它是检测任务（有框）、12 类、
> 数据量大 14 倍，而且官方公开了测试集标注，可以在 Kaggle 上提交排名。

### 其他阻碍

| 数据集 | 阻碍 |
|---|---|
| HuggingFace 上的各类 solar/PCB 数据集 | 站点本机不可达 |
| Kaggle 上的 Solar / Solder / PCB 数据集 | 需要账号 token |
| Roboflow 上的光伏缺陷集 | 403，需要 API key |
| MVTec AD（工业异常检测基准） | 官网可达，但要填表 + 邮箱 |

## 五、只有代码、没有数据的仓库（别被 star 数骗了）

实测下载后逐个核对，这些仓库**不含图像数据**：

| 仓库 | 实际情况 |
|---|---|
| `lyc686/MNFI-Net`（★12） | 80 MB zip，255 MB 解压，其中 106 张 jpg 全是 ultralytics 的 `bus.jpg`/`zidane.jpg` 样例；80% 体积是 wandb 日志。**没有数据集** |
| `QQ767172261/How-to-...-1108-ima` | 仓库只有 11 KB 的 README，**一张图都没有** |
| `wch313/PSCDE-Dataset`（★13） | 只有 3 张示意图 + 一个 `BSRA` 目录，无图像数据 |
| `abj247/PV-S3`（★6） | 有 `dataset/` 目录，但前 3 层内 0 张图，5 个 txt |
| `binyisu/PVEL-AD`（★175） | 见上，数据在网盘 |

**教训**：GitHub 搜索结果的 star 数和"有没有数据"完全无关。
**必须先列目录、数文件，再决定要不要花时间。**

## 七、给你的建议

### 今天（答辩）

**不要动数据。** 现在的指标是在 ELPV 上跑出来的，换数据集就得重训、重评、
重出报告，答辩前 12 小时做这件事**只会让结果不可信**。

被问到"为什么只用 ELPV"，标准答法：

> "ELPV 是唯一能直接拿到真图像、又带标注的 EL 公开集。
> PVEL-AD 有 36543 张、12 类、4 万个框，但它要填表申请、数据在网盘，
> 我没在答辩前拿到。这个我已经列入下一步——
> 它有框，所以可以直接把现在的分级模型升级成检测模型。"

这段话把"数据少"变成了"我知道更好的在哪、也知道怎么用"。

### 答辩后（按优先级）

1. **拿 PVEL-AD**（填表 + 申请）。有框 → 从分级升级到检测，指标可上 Kaggle 排名。
2. **用 DM-PV 做跨场景实验**（已可下）。回答"电池片级和组件级差多少"。
3. **NEU-DET 做跨领域实验**。回答"这套方法换到钢表面还成立吗"。
